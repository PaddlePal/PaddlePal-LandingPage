# Image assets

Drop files here with these **exact** names. `ImageSlot` shows a dashed
placeholder until the file exists, then swaps in automatically — no code change.

| File | Dimensions | Used for |
| --- | --- | --- |
| `app-live.png` | 1170 × 2532 | App preview — live session screen |
| `app-stats.png` | 1170 × 2532 | App preview — shot analytics screen |
| `app-history.png` | 1170 × 2532 | App preview — session history screen |
| `og-image.png` | 1200 × 630 | Social share card |
| `paddle-hero.png` | ~900 × 1200, transparent bg | Optional — replaces the SVG paddle in the hero |

Compress before committing (TinyPNG / `pngquant`). Uncompressed iPhone
screenshots are ~2 MB each and will dominate page load.
